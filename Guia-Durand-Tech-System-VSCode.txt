1) ESTRUTURA QUE TEM QUE ESTAR NO VSCODE
------------------------------------------------
durand-tech-system/
│
├── api/
│   └── index.py        <- SEU BACKEND FLASK (Juliana)
│
├── index.html          <- SEU SITE (frente)
├── style.css           <- (se tiver)
├── script.js           <- (se tiver)
├── requirements.txt    <- dependencias python
└── vercel.json         <- config da Vercel

Conteúdo do api/index.py tem que começar com:
from flask import Flask, request, jsonify
app = Flask(__name__)
...

Conteúdo do vercel.json TEM QUE SER ESSE (Other, não Flask):
{
  "rewrites": [
    { "source": "/api/:path*", "destination": "/api/index.py" },
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}

Conteúdo do requirements.txt:
Flask
Flask-Cors
groq
gunicorn

------------------------------------------------
2) COMANDOS NO TERMINAL DO VSCODE (CTRL + ')
------------------------------------------------

# Entrar na pasta do projeto
cd caminho/para/durand-tech-system

# Ver se tá tudo ok
git status

# Adicionar tudo que mudou
git add .

# Salvar com mensagem
git commit -m "atualizei o site"

# Enviar pro GitHub (e Vercel faz deploy automatico)
git push

Pronto, 3 comandos: add . / commit -m / push

------------------------------------------------
3) SE DER ERRO DE BUILD NA VERCEL
------------------------------------------------

Vercel > Seu Projeto > Settings > Build and Deployment

- Framework Preset: Other
- Build Command: (deixar vazio)
- Output Directory: (deixar vazio)
- Install Command: (deixar vazio)

Depois: Deployments > 3 pontinhos do ultimo deploy > Redeploy > DESMARCA "Use existing Build Cache" > Redeploy

------------------------------------------------
4) CONECTAR DOMINIO LOCAWEB (JA FEITO)
------------------------------------------------

Você já fez, mas pra lembrar:

Locaweb > Dominios > durandtechsystem.com.br > Gerenciar DNS > Zona DNS

Entrada 1:
Tipo: A
Nome: @ (em branco)
Valor: 76.76.21.21

Entrada 2:
Tipo: CNAME
Nome: www
Valor: cname.vercel-dns.com

Na Vercel: Settings > Domains > Add Domain > durandtechsystem.com.br + www.durandtechsystem.com.br

Esperar 2h e fica verde com SSL.

------------------------------------------------
5) TESTAR SE A JULIANA TA FUNCIONANDO
------------------------------------------------

Depois do deploy:

1. Abre: https://durandtechsystem-com-br-7tx1.vercel.app/api/
Tem que aparecer JSON, não tela preta.

2. Abre: https://durandtechsystem-com-br-7tx1.vercel.app
Tem que abrir seu site.

Se abrir JSON na raiz, é porque Framework tá Flask. Troca pra Other e redeploy.
